# Kenneth Fronda — Solar PV Portfolio

Static responsive portfolio for Solar PV / CAD / residential solar job applications.

## Privacy and confidentiality
The public portfolio uses **sanitized visual excerpts only** from supplied work files. It does not publish the original project PDFs.

Removed/omitted from public samples:
- Customer names
- Home/site addresses
- Phone numbers and email addresses
- Utility account information
- Project IDs / community IDs
- Coordinates
- Company title blocks and identifying project metadata
- Proprietary/confidential notices and other identifying information

The work samples are presented as technical references, not as public copies of the original employer/customer documents. Confirm you are authorized to publish any work sample before using it publicly.

## Files
- `index.html` — website
- `Kenneth_Fronda_CV.pdf` — original supplied CV
- `Sanitized_Work_Samples.pdf` — sanitized technical excerpts
- `assets/` — sanitized portfolio images
